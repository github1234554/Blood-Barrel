# BLOOD BARREL(In Development)

## The idea
**Blood Barrel is a fast paced 2D Roguelike where your parasitic shotgun constantly needs blood and will gladly take it from you... but you might want that.**

Inspired by how bad the MacBook Air 2020 M1 is for gaming, this game is a personal project intended to have very minimal computer requirements and to run smoothly on most **low-end devices**.
While there is no strict age limit, this game is meant for a more mature audience as its main mechanic is **blood**.
The imagery and combat may be too violent for smaller ages or those with **fear of blood (homophobia)** so be advised.

## Development
### Current progress
Blood Barrel is still under **EARLY DEVELOPMENT** and is **NOT AVAILABLE FOR DOWNLOAD** as of now.

Currently developing the **Collision Handler** which will allow collision between multiple objects rather than just the current max of 2, as well as soon handling unique collision responses for entities and even levels.
At the current pace the first prototype of the game is set to release **late December** however this isn't a definitive date.
